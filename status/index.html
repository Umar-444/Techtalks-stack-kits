How to read this

  • Verified — every eval task defines a real command, the executed ones passed, and the starter ships at least 250 lines of source.
  • Partial — some tasks ran and passed; others have no verify command yet.
  • Pending toolchain — every task defines a real verify command, but the language toolchain (Go, Rust, Bun, Elixir, Ruby) is not installed on the machine that produced this board. CI with it installed executes them.
  • Scaffold — rules, security manifest and structure are complete and drift-checked, but nothing has been executed. Useful as an agent context pack; not yet a runnable application.
  • Context tokens — measured with tiktoken cl100k_base: what an agent must read before writing code. Tokens to complete a build are not measured, because that needs a live agent run.
