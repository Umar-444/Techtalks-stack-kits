Frequently Asked Questions

Got Questions?

Everything you need to know about TechTalks Stack Kits and security playbooks.

What is a stack kit? ↓

A stack kit is a pre-configured production blueprint combining a modern backend, frontend, and database with pre-wired AI agent rules (Cursor, Claude Code, Copilot, Cline, Codex, Antigravity), runnable starter containers, security invariants, and benchmark evals.

Which agents are supported? ↓

Every kit provides single-source agent rules compiled to 6 native dialects: Cursor (.cursor/rules/*.mdc), Claude Code (CLAUDE.md), GitHub Copilot (.github/copilot-instructions.md), Cline / Roo (.clinerules), OpenAI Codex (CODEX.md), and Antigravity (.agents/rules/*.md).

Is it free and open source? ↓

Yes. TechTalks Stack Kits is released under the permissive MIT License. You can freely clone, modify, and use all kits and security guides in commercial or private projects.

Can I contribute a kit? ↓

Yes! We welcome community contributions. Every new kit must include a valid kit.yaml manifest, starter container, single-source rules, skills, security scanners, and benchmark tasks evaluated by evals/runner.py.

How is this different from a starter template? ↓

Traditional templates only provide source files. A TechTalks Stack Kit includes five unified layers: a physical starter container, transpiled agent rules for 6 AI coding tools, reusable agent skills, an opinionated design system (DESIGN.md), and automated security scanners (Gitleaks + Semgrep).
