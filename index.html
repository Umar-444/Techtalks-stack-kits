06 / PRINCIPLES

Engineered for engineering rigor

Six engineering assertions that guide every line of configuration and rule in this repository.

01 / DETERMINISTIC

Deterministic Over Conversational

Rules and skills are concrete code artifacts, not conversational prompts. When an agent runs a kit, every build produces identical invariants.

02 / COMPILER GATE

Security as a Compiler Error

Insecure code must fail the build. Scanners like Gitleaks and Semgrep reject pull requests before human review or deployment.

03 / TOKEN BUDGET

Token Efficiency as a Metric

Kits keep agent rule contexts compact (under 15k tokens). Bloated instructions cause context degradation and hallucinated APIs.

04 / ROOTLESS ISOLATION

Rootless and Isolated by Default

Kits execute in unprivileged container environments. Agent tools never have raw host access, preventing rogue file writes.

05 / DIALECT NATIVE

Dialect-Native, Never Transpiled Slop

Every agent format has unique capabilities. We compile rules into the exact idiom of each tool rather than dumping generic markdown.

06 / COMPLETE STACKS

Complete Stacks, Zero Placeholders

Real migrations, real authentication, real tests, and real CSS tokens. We build production systems, not toys or demo apps.
