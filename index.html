PRINCIPLES

Engineered for engineering rigor

Autonomous code generation without architectural boundaries creates exponential technical debt. We build the boundary rails.

01 • Deterministic

Zero Architectural Hallucinations

Coding agents frequently invent directory layouts, non-existent libraries, or obsolete configuration formats. Our single-source rules constrain LLM sampling to verified paths, patterns, and framework conventions.
02 • Multi-Dialect

Single-Source Agent Transpilation

Maintain your system rules once in master YAML manifests. Our transpiler compiles them deterministically for Claude Code (CLAUDE.md), Cursor (.cursorrules), OpenAI Codex (AGENTS.md), Windsurf, Roo Code, and Google Antigravity.
03 • Open Source

Permissive MIT Licensing

Everything is transparent and completely open. No telemetry, no lock-in, no SaaS paywalls. Clone the repositories directly into your enterprise cloud, internal Git servers, or local workstation.
FAQ

Frequently asked questions

Clear answers about how TechTalks Stack Kits integrate with modern autonomous coding workflows.

What makes a Stack Kit different from a starter template? ↓

Traditional templates only provide raw source code. A TechTalks Stack Kit includes five unified layers: a physical starter container, transpiled agent rules for 6 coding dialects, reusable agent skills, an opinionated design system (DESIGN.md), and automated CI security scanners (Gitleaks + Semgrep).

Which AI coding agents and IDEs are supported? ↓

Every kit compiles native dialect rules for Claude Code, Cursor, OpenAI Codex, Windsurf, Roo Code, and Google Antigravity. Simply clone the kit and start chatting with your agent in your preferred tool.

Are these kits completely free for commercial projects? ↓

Yes. TechTalks Stack Kits is released under the permissive MIT License. You can freely clone, modify, and use all kits and security guides in commercial or private projects without royalties or restrictions.

How do the automated security scanners work? ↓

Each repository includes a preconfigured GitHub Actions workflow that executes Gitleaks (detecting API keys, secrets, and credentials) and Semgrep (scanning for OWASP Top 10 vulnerabilities, insecure deserialization, and SQL injections) before code can merge.

Can I contribute or request a new kit? ↓

Yes! We welcome community contributions. Every new kit follows our kit.yaml specification and must pass the automated benchmark suite in evals/runner.py. Submit a proposal on GitHub Discussions to get started.
