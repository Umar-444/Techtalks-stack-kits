# Design System: Next.js 15 Modern Dashboard

## 1. Principles
- **Modern Simplicity**: Clean typography, minimal borders, subtle elevation shadows.
- **Theme Support**: Flawless dark theme (`#090d16` background) and light theme (`#ffffff`).
- **WCAG AA Compliance**: High-contrast ratios (> 4.5:1 text, > 3:1 interactive components).

## 2. Color Palette
- **Primary / Brand**: Blue 600 (`#2563eb` light, `#3b82f6` dark)
- **Neutral Dark**: Slate 950 (`#090d16`), Slate 900 (`#0f172a`), Slate 800 (`#1e293b`)
- **Neutral Light**: Slate 50 (`#f8fafc`), Slate 100 (`#f1f5f9`), Slate 200 (`#e2e8f0`)
- **Success**: Emerald 500 (`#10b981`)
- **Danger / Warning**: Rose 500 (`#f43f5e`) / Amber 500 (`#f59e0b`)

## 3. UI Component Hierarchy
- **Header**: Navigation links, workspace selector, user avatar with dropdown.
- **Card Grid**: Responsive 12-column layout displaying projects with progress indicators.
- **Modal Dialog**: Accessible accessible dialog for creating and updating tasks.
