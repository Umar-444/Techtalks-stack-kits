# Design System: MCP Headless & Inspector Interface

## 1. Principles
- **Headless Precision**: Protocol payloads adhere strictly to JSON-RPC 2.0 with structured error codes.
- **Console Typography**: High-readability ANSI log output with categorized tags (`[MCP-INIT]`, `[TOOL-EXEC]`, `[SECURITY-PASS]`).
- **Web Inspector Support**: Clean dark theme (`#090d16` background) with JSON syntax highlighting for tool payload debugging.
- **WCAG AA Compliance**: High-contrast ratios (> 4.5:1 text, > 3:1 schema badges).

## 2. Color Palette
- **Primary / Protocol**: Emerald 500 (`#10b981` light, `#059669` dark)
- **Neutral Dark**: Slate 950 (`#090d16`), Slate 900 (`#0f172a`), Slate 800 (`#1e293b`)
- **Neutral Light**: Slate 50 (`#f8fafc`), Slate 100 (`#f1f5f9`), Slate 200 (`#e2e8f0`)
- **Warning / Sandbox Violation**: Rose 500 (`#f43f5e`)
