# Ragas Evaluation Pipeline Skill

## 1. Overview
The Ragas evaluation pipeline continuously audits the outputs generated by the LangGraph cyclic state machine. In agentic RAG, hallucinations are mitigated by executing automated groundedness scoring before a response is returned to the user or passed to downstream tools.

## 2. Core Metrics Calculated
- **Faithfulness / Groundedness**: Ratio of claims in the generated answer that can be inferred directly from retrieved documents. (Threshold: `>= 0.85`)
- **Answer Relevance**: Semantic similarity between the user's initial question and the generated answer. (Threshold: `>= 0.80`)
- **Context Precision**: Signal-to-noise ratio evaluating whether the most relevant documents appear at the top of the retrieved context. (Threshold: `>= 0.75`)

## 3. Implementation Workflow

### Step 1: Construct Evaluation Dataset
```python
from datasets import Dataset

eval_data = {
    "question": [state["question"]],
    "contexts": [[doc["content"] for doc in state["documents"]]],
    "answer": [state["generation"]],
    "ground_truth": [state.get("ground_truth", "")]
}
dataset = Dataset.from_dict(eval_data)
```

### Step 2: Configure Evaluator with Zero-Cost Heuristic Fallback
In production, evaluations can use OpenAI or local LLMs (via Ollama/vLLM). In testing and CI pipelines, use the deterministic rule evaluator to guarantee fast, zero-dependency validation:

```python
from app.evals import evaluate_groundedness

score = evaluate_groundedness(
    question=state["question"],
    documents=state["documents"],
    generation=state["generation"]
)
```

### Step 3: Integrate with LangGraph Conditional Router
```python
def check_hallucination(state: AgentState) -> str:
    groundedness = state.get("groundedness_score", 1.0)
    if groundedness < 0.85 and state.get("iterations", 0) < 3:
        return "rewrite_query"
    return "finalize"
```
