## Architectural Directives
1. **Cyclic Control Flow**: Implement Self-RAG cycles: `retrieve -> grade_documents -> [rewrite_query -> retrieve] / [generate -> grade_generation] -> END`.
2. **State Immutability**: Define state as a `TypedDict`. Nodes must never mutate state in place; return dict deltas.
3. **Recursion Limit**: Enforce bounded execution: `config={"recursion_limit": 15}` and track `iteration_count`.
4. **Qdrant Isolation**: All vector queries must enforce payload filters matching `tenant_id` and score thresholds (`score_threshold=0.65`).
5. **Groundedness Verification**: Grade output against retrieved chunks to eliminate hallucinations before returning answers.
6. **Container Security**: Multi-stage rootless Docker container (`USER 10001:10001`).

SECTION 4 • FREQUENTLY ASKED QUESTIONS

Kit FAQ & Operational Details

14 QUESTIONS
Why choose LangGraph over linear RAG pipelines for enterprise retrieval? ↓

Linear RAG chains assume that the initial user query always retrieves the right documents in a single pass. In reality, complex queries often retrieve irrelevant or ambiguous context, leading to hallucinations. LangGraph introduces a cyclic state machine: an agent can evaluate retrieved documents, reformulate the search query, perform additional retrieval passes, and verify output groundedness before returning a response.

How does LangGraph handle cyclic execution loops and prevent infinite query rewriting? ↓

Every cycle increments an explicit `iterations` counter in the `AgentState`. The conditional edge functions inspect both document quality and iteration count against `max_iterations` (default: 3). Once the recursion ceiling is reached, the graph deterministically branches to fallback synthesis rather than continuing to loop.

How does Qdrant payload filtering enforce multi-tenant isolation in RAG applications? ↓

Qdrant stores document payloads as structured JSON alongside dense vector embeddings. During vector search, Qdrant evaluates metadata filter conditions (e.g. `Must(FieldCondition(key='tenant_id', match=MatchValue(value=tenant_id)))`) at the HNSW segment level before vector distance calculation, mathematically preventing cross-tenant data leakage.

What is the difference between Ragas faithfulness and answer relevancy metrics? ↓

Faithfulness (groundedness) measures whether every claim made in the generated answer can be inferred directly from the provided source documents (evaluating hallucination). Answer relevancy measures whether the answer actually addresses the user's initial question regardless of document accuracy (evaluating off-topic divergence).

How does the document grading node determine whether retrieved documents are relevant? ↓

The document grading node evaluates semantic similarity scores and key entity overlaps between the query and chunk contents. Documents falling below the relevance score threshold are discarded from the state, triggering query reformulation if no sufficiently relevant documents remain.

How is human-in-the-loop review integrated into LangGraph state graphs? ↓

LangGraph supports human-in-the-loop approval via persistent checkpointers (such as `MemorySaver` or Postgres checkpointer) using `interrupt_before=['human_review']`. When the state reaches the interrupt node, execution suspends until an operator or reviewer reviews the generated synthesis and submits an approval payload via API.

What embedding models and distance metrics are recommended for Qdrant vector collections? ↓

For multilingual dense embeddings, BAAI/bge-m3 (1024 dims) or OpenAI text-embedding-3-small (1536 dims) paired with Cosine similarity distance are industry standards. Qdrant HNSW indexing performs optimal graph traversal on normalized cosine embeddings with minimal memory footprint.

How does the rewrite_query node reformulate questions to improve semantic retrieval? ↓

The `rewrite_query` node strips conversational filler words ('can you please tell me about'), resolves coreferences ('what about its latency?'), and converts user questions into keyword-dense, semantic search queries optimized for vector similarity search.

How can I run Ragas evaluations in CI without incurring external LLM API costs? ↓

In CI and automated test environments, our starter provides a deterministic heuristic evaluation engine based on claim extraction and token overlap ratios. This verifies the evaluation contract and thresholds in milliseconds with zero network egress or API charges.

How do you scale Qdrant when indexing millions of document chunks? ↓

Qdrant scales horizontally using collection sharding and distributed consensus via Raft. For high-volume production, configure scalar quantization (SQ) or product quantization (PQ) to compress vector RAM requirements by up to 4x while maintaining >95% search recall.

What security guardrails prevent prompt injection from retrieved external documents? ↓

Retrieved documents are treated as untrusted user inputs. The generator wraps document chunks in strict XML delimiting tags (`...`) and uses system prompts instructing the model never to follow instructions contained within document chunks.

Why run FastAPI with rootless Docker (UID 10001) instead of default root? ↓

Running containers as root violates the principle of least privilege. In the event of a container escape vulnerability or remote code execution, a non-root process UID 10001 lacks host superuser privileges, preventing host takeover and satisfying strict enterprise compliance standards.

How does the LangGraph checkpointer maintain conversation history across multiple turns? ↓

LangGraph checkpointers save serialized snapshots of the state graph keyed by `thread_id`. Subsequent requests passing the same `thread_id` resume execution with the accumulated conversation history, document citations, and iteration logs intact.

Can LangGraph state machines integrate with external tool APIs (e.g. calculators, SQL agents)? ↓

Yes. LangGraph provides `ToolNode` which seamlessly binds LangChain tools. An agent node inspects the state, emits tool call requests (e.g. `query_sql_database` or `fetch_stock_price`), and the graph routes to `ToolNode` before returning execution to the generator.
