# SeaORM and SQLite WAL Mode Configuration

1. **SQLite Concurrency Optimization**: Configure SQLite connections with Write-Ahead Logging (`PRAGMA journal_mode = WAL;`), busy timeout (`PRAGMA busy_timeout = 5000;`), and synchronous normal (`PRAGMA synchronous = NORMAL;`). This enables non-blocking concurrent reads while serialized writes execute safely.
2. **SeaORM ActiveModel Safety**: Interact with SQLite tables exclusively through SeaORM `ActiveModelTrait` and typed entity columns. Parameterized queries (`?1`, `?2`) are automatically generated by the query compiler, eliminating SQL injection.
3. **Loco Migration Workflow**: Author migrations in `migration/src/` using declarative SeaQuery table builders. Apply migrations via `cargo loco db migrate` and test schema rollbacks via `cargo loco db rollback`.
4. **File Path and Volume Persistence**: Store SQLite database files in a designated writable data directory (`storage/` or `/data/db.sqlite`). Mount this directory as an isolated Docker volume in production containers.
5. **Atomic Transactions**: Enforce database consistency during multi-step mutations by wrapping operations in `db.transaction::<_, _, DbErr>(|txn| Box::pin(async move { ... }))`.
