Architectural Standard

The 6-Layer Anatomy of Every Kit

Most starters dump files without instructions. TechTalks kits follow an unshakeable 6-layer anatomy verified by automated CI checks.

01

starter/

The minimal, clean, working skeleton. Tested Docker Compose, seeders, environment configurations, and pre-wired database connections.

02

rules/source/*.md

Single source of truth. Numbered, topic-focused rules transpiled via tools/transpiler.py into Cursor, Claude, Codex, Copilot, Antigravity, and Windsurf formats.

03

skills/SKILL.md

Standard agent skills adhering to the Anthropics/Agent Skills spec. Teaches agents complex procedures (like creating a Filament resource or adding an API endpoint) without hallucination.

04

DESIGN.md

Strict design tokens, curated color palettes, WCAG AA contrast rules, typography scales, and dark mode guidelines that prevent chaotic UI drift.

05

security/

Non-negotiable security layer. Pre-configured Gitleaks, Semgrep rulesets, OWASP Top 10 defenses, authorization policies, and architecture test assertions.

06

agent-build-steps.md

Numbered, step-by-step prompts for agents with explicit acceptance criteria. Tells the agent exactly what to build, how to test it, and how to verify completion.

Single-Source Architecture

Write Rules Once.
Generate for 6 Agent Dialects.

Don't maintain separate rule files that drift apart. TechTalks uses tools/transpiler.py to compile small, single-topic source files into the native formats of all major coding assistants.

Cursor .cursor/rules/*.mdc (with globs)
Claude Code CLAUDE.md (concatenated rules)
Codex & Universal AGENTS.md (root index)
Google Antigravity .agents/rules/*.md
GitHub Copilot .github/copilot-instructions.md
Windsurf .windsurfrules

Instant Agent Kickoff

Ready to Build? Paste This into Your Agent

Copy this universal kickoff prompt directly into Claude, Cursor, Codex, or Antigravity to run any kit seamlessly. 

You are building with TechTalks Stack Kits.
1. Read and adhere strictly to AGENTS.md (or your IDE's native rules).
2. Follow DESIGN.md tokens and dark mode standards.
3. Execute and verify each task in steps/agent-build-steps.md.
4. Enforce non-negotiable security checks in SECURITY.md (no hardcoded secrets, parameterized queries, authorization checks).
Report in the evidence format: Done, Files, Verified, Not verified.
