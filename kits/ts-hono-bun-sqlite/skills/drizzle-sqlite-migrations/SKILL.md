# Drizzle SQLite Migrations Skill

## Core Commands
1. **Generate Migration Files**:
   ```bash
   bun x drizzle-kit generate
   ```
2. **Apply Migrations to SQLite**:
   ```bash
   bun x drizzle-kit migrate
   ```
3. **Inspect Database with Drizzle Studio**:
   ```bash
   bun x drizzle-kit studio
   ```
